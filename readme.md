# R2 机器人机械臂控制系统

基于 STM32F407 + FreeRTOS 的多轴机械臂控制程序，实现方块自动吸取、存放、取回及武器夹持等任务。

## 技术栈

- **MCU:** STM32F407
- **RTOS:** FreeRTOS 
- **电机驱动:** 达妙电机 (DM Motor) + 大疆电机 (DJI Motor)，通过 CAN 总线通信
- **遥控:** DBUS 协议（大疆遥控器）
- **执行器:** 气泵吸取、电磁阀气缸夹持
- **开发工具:** Keil MDK-ARM VsCode Trae CodeX

## 核心功能

### 状态机架构

采用 5 状态有限状态机（FSM）管理任务调度，通过遥控器拨杆实时切换：

```
INIT ──(ch9)──> TASK1(取方块) <──(ch9)──> TASK2(放方块)
                                      |
                               (ch10) v
                              TASK3(武器张开) --> TASK4(武器闭合)
```

### 方块任务 (Task 1 & 2)

- **多阶段执行:** 每个任务拆分为多个 phase，各阶段独立控制时序
- **到位检测:** 基于电机速度反馈 (`vel < 0.05`) 判断运动完成，避免盲等
- **防误判机制:** 延时 + 速度双重判断，防止电机启动瞬间速度为 0 导致误触发
- **自适应高度:** 遥控器 ch[7/8/9] 通道信号对应三种方块高度，支持不同高度方块的吸取

### 武器任务 (Task 3 & 4)

- 电磁阀控制气缸开合，实现武器夹持与释放

### 电机初始化

- 自动寻找机械零位：通过力矩突变检测触碰限位，保存当前位置为零位

## 项目结构

```
application/
├── arm_task.c     # 机械臂动作函数（task0~task4, sleep, save_zero）+ 共享变量定义
├── arm_task.h     # 宏定义、状态枚举、extern变量声明、函数声明
├── test_task.c    # 状态机主循环：遥控器信号 → 状态调度
├── test_task.h    # test_task 函数声明
└── readme.md
```

## 控制逻辑示例

```c
// 阶段切换：延时防抖 + 速度到位判断
if ((currentTime - phaseEntertime) > pdMS_TO_TICKS(2000) && fabsf(vel) < 0.05f) {
    task1_phase = 1;  // 电机到位，进入下一阶段
}
```

## 更新日志

### 2026-05-03（代码重构）
- **文件拆分：** 将 test_task.c 中的动作函数、共享变量、宏定义、枚举拆分到 arm_task.c/h 模块，test_task.c 仅保留状态机主循环
- **模块职责：** arm_task.c/h 负责机械臂动作逻辑，test_task.c 负责遥控器信号解析与状态调度，实现调度与执行分离

### 2026-05-03
- **状态机重构：** 合并原 task1 + task2 为统一的 phase 架构，单个任务内实现多阶段自动切换
- **自适应取方块高度：** 遥控器 ch[7/8/9] 分别对应 115/95/75 三种吸取高度
- **多轮取方块计数：** 新增 `store_count` 实时记录车上方块数量，第1个存300位置，第2个存400位置，第3个仅吸取不存放
- **自动轮回机制：** task1 完成后自动回 STATE_SLEEP，用户拨回通道即可再次触发，支持连续取1~3个方块
- **车满保护：** 存满2个方块后（store_count>=3），task1 停在 phase1，气泵保持开启防止脱落
- **state_sleep 休眠态：** 新增 STATE_SLEEP 状态，根据 store_count 自动控制气泵（满3个保持开泵，否则关闭）
- **task2 放方块改造：** 根据 store_count 区分三种放方块场景（1个/2个/3个），ch6 为放方块模式开关，ch[7/8/9] 控制放置高度（115/145/175），每次放完自动 store_count--
- **phase 到位检测优化：** 采用 `prev_phase` 机制实现 phase_entertime 自动重置，避免重复赋值
- **遥控器操作方式：** 采用叠加拨杆设计，取/放方块时拨下通道触发，完成后手动拨回
