# test_task.c 模块文档

## 概述

`test_task.c` 是机器人机械臂任务控制模块，负责管理方块的吸取、存放、取回以及武器夹持等操作。该模块基于 FreeRTOS 运行，通过状态机（State Machine）架构实现多任务调度，配合遥控器拨杆信号进行任务切换。

## 状态机枚举

```c
typedef enum {
    STATE_INIT = 0,   // 初始化状态
    STATE_TASK1,      // 取方块任务
    STATE_TASK2,      // 放方块任务
    STATE_TASK3,      // 武器夹持-张开
    STATE_TASK4,      // 武器夹持-闭合
} system_state_t;
```

## 核心函数

### `test_task()`

**功能：** 主任务循环，FreeRTOS 任务入口。

**参数：** `void const * argument`（未使用）

**返回值：** 无

**执行流程：**

1. 调用 `save_zero()` 保存电机零位
2. 调用 `damiao_init()` 初始化达妙电机
3. 进入无限循环，每个循环：
   - 获取遥控器数据指针
   - 检测状态切换并记录时间戳
   - 检测拨杆 ch[10]：非零时强制切换到 `STATE_TASK3`
   - 根据 `current_state` 执行对应的状态函数

**状态切换逻辑：**

| 当前状态 | 切换条件 | 目标状态 |
|----------|----------|----------|
| `STATE_INIT` | `ch[9] == 1` | `STATE_TASK1` |
| `STATE_TASK1` | `ch[9] == 0` | `STATE_TASK2` |
| `STATE_TASK2` | `ch[9] == 1` | `STATE_TASK1` |
| `STATE_TASK3` | `ch[10] == 0` | `STATE_TASK4` |
| `STATE_TASK4` | `ch[9] == 1` | `STATE_TASK1` |

---

### `state_task1()`

**功能：** 取方块任务 —— 机械臂伸出吸取方块、抬升、存放、归位。

**参数：** 无

**返回值：** 无（static 函数）

**阶段详解：**

#### Phase 0：伸出 + 下降吸取

1. **电机动作：** 电机1,2运动到600（前伸到位），电机5运动到0
2. **等待条件：** 2秒延时 + 电机1速度 < 0.05（电机1到位）
3. **条件满足后：** 电机3,4下降到75 + 开启气泵
4. **切换条件：** 12秒延时 + 电机3速度 < 0.05（确保方块被吸住）

#### Phase 1：抬升

1. **持续动作：** 保持气泵开启 + 电机3,4上升到115
2. **切换条件：** 2秒延时 + 电机3速度 < 0.05

#### Phase 2：存放

1. **电机动作：** 电机1,2收缩到300，电机5旋转到4.52（移到存放位置）
2. **切换条件：** 2秒延时 + 电机1速度 < 0.05 → 关闭气泵（释放方块）

#### Phase 3：归位准备

1. **等待条件：** 2秒延时 + 电机1速度 < 0.05
2. **条件满足后：** 电机3,4归零，电机5归零
3. **切换条件：** 5秒延时 + 电机3速度 < 0.05
4. **否则：** 电机1,2运动到500（中间位置）

#### Phase 4：完全归位

1. **电机动作：** 电机1,2归零

---

### `state_task2()`

**功能：** 放方块任务 —— 机械臂伸出、吸取方块、归位存放、释放。

**参数：** 无

**返回值：** 无（static 函数）

**阶段详解：**

#### Phase 0：伸出到位

1. **电机动作：** 电机1,2运动到400，电机3,4运动到115
2. **切换条件：** 2秒延时 + 电机1速度 < 0.05 且 电机3速度 < 0.05

#### Phase 1：吸取

1. **电机动作：** 电机1,2继续收缩到290（靠近方块），电机5旋转到-1.56
2. **气泵动作：** 开启气泵
3. **切换条件：** 6秒延时 + 电机1速度 < 0.05

#### Phase 2：归位

1. **电机动作：** 电机1,2运动到600（缩回）
2. **等待条件：** 2秒延时 + 电机1速度 < 0.05
3. **条件满足后：** 电机5旋转到-4.5（移到放方块位置）→ 切换 phase 3

#### Phase 3：释放

1. **等待条件：** 8秒延时
2. **条件满足后：** 关闭气泵 + 所有电机归零

---

### `state_task3()`

**功能：** 武器夹持张开 —— 张开气缸、下降、旋转。

**参数：** 无

**返回值：** 无（static 函数）

**执行流程：**

1. 关闭电磁阀2 → 开启电磁阀1（气缸张开）
2. 电机3,4下降到125
3. 电机5旋转到-1.56

---

### `state_task4()`

**功能：** 武器夹持闭合 —— 闭合气缸、延时后抬升。

**参数：** 无

**返回值：** 无（static 函数）

**执行流程：**

1. 关闭电磁阀1 → 开启电磁阀2（气缸闭合）
2. 延时 3 秒
3. 电机3,4上升到220

---

### `state_task0()`

**功能：** 初始化 —— 将所有电机设置为0位置，通过力矩变化检测电机3,4的机械零位。

**参数：** 无

**返回值：** 无（static 函数）

**执行流程：**

1. 电机1,2,5归零
2. 电机3,4向-80方向运动（寻找机械限位）
3. 检测力矩突变（`diff3 > 10.0` 或 `diff4 > 12.0`）→ 判定到达机械限位
4. 到达限位后：保存当前位置为零位，停止运动
5. `stop` 标志防止重复检测

---

### `save_zero()`

**功能：** 保存电机1-4的当前位置为零位。

**参数：** 无

**返回值：** 无（static 函数）

**执行流程：**

依次对电机1,2,3,4调用 `save_pos_zero()` 保存零位，每次间隔 100ms。

## 阶段切换的通用机制

每个任务内部使用 `phase_entertime` 记录进入新阶段的时间戳，并配合以下条件判断是否允许切换到下一阶段：

```c
if ((xCurrentTime2 - phase_entertime) > pdMS_TO_TICKS(延时毫秒) && fabsf(速度) < 0.05f)
```

- **延时条件：** 防止电机启动瞬间速度为0导致误判
- **速度条件：** 确认电机已转动到位并停止

每次切换阶段时，`phase_entertime` 会自动重置：

```c
static uint8_t prev_phase = 0xFF;
if (task1_phase != prev_phase) {
    phase_entertime = xCurrentTime2;
    prev_phase = task1_phase;
}
```

## 遥控器控制说明

| 拨杆 | 通道 | 功能 |
|------|------|------|
| `ch[9]` | 拨杆1 | 在 INIT/TASK1/TASK2 之间切换 |
| `ch[10]` | 拨杆2 | 强制进入 TASK3（武器夹持），复位后回到 TASK4 |

## 后续开发规划

1. **取不同高度方块：** 使用三个数值的拨杆代表不同高度，只需修改取方块的高度参数
2. **存放逻辑：** 定义计数器 `i` 记录已存放方块数量，`i=0` 放里面，`i=1` 放外面
3. **取方块逻辑：** 根据存放位置判断应该取外面还是里面的方块
4. **完善 task3,4：** 补充武器夹持的完整动作序列
